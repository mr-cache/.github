# Security

Do not post vulnerability details, credentials, tokens or customer data in public issues or pull requests.

A dedicated private reporting channel is not currently listed by this project. Until one is announced, do not use the public issue tracker to disclose exploit details. This document does not promise a response deadline or designate an unverified contact address.

Treat Redis as a trusted data store. Cache payloads may contain raw attributes hidden from model output; isolate access, protect credentials and review the consistency guarantees of your installed package version.
