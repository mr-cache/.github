# Support

For public, non-sensitive questions, use [MrCache issues](https://github.com/mr-cache/mr-cache/issues).

Include your installed package version, PHP/Laravel/Redis/client versions, a minimal reproduction with synthetic data, and whether transactions, replicas or external writers are involved. Remove credentials, private bindings and customer rows before sharing configuration or output.

Check the [package README](https://github.com/mr-cache/mr-cache#readme) and the documentation for your installed version first.

For security concerns, read [SECURITY.md](SECURITY.md). Do not disclose vulnerabilities or sensitive data in a public support issue.
